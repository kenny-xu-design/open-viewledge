# Contributing to Viewledge

Thank you for your interest in Viewledge.

Bug reports, feature requests, reproducible test cases, documentation
corrections, and general discussion are welcome through GitHub Issues.

## Code contributions

Viewledge uses an AGPL community license together with the possibility of
separate commercial licensing.

Before a contributor agreement or other inbound licensing policy is formally
published, unsolicited code pull requests may not be merged into the
dual-licensed core.

Please open an Issue before preparing a substantial code contribution.

Do not submit code, media, models, datasets, documentation, or other material
unless you have the right to contribute it.

## Security and private information

Do not include API keys, cookies, account credentials, private videos,
copyrighted media, generated user knowledge packages, personal data, or
other sensitive information in Issues or pull requests.
