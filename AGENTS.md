# Codex Working Rules

- Keep project documentation in `README.md`, `AGENTS.md`, and `docs/`.
- Store conversation summaries in `docs/codex-log.md`; do not place full chat transcripts in the project root.
- Store durable technical decisions in `docs/decisions.md`.
- Do not put Codex logs or decision notes under business source directories such as `src/`.
- Avoid changing business code unless the task explicitly asks for it.
