# Viewledge 零基础使用

## 第一次启动

1. 在 Windows 10 或 Windows 11 安装 Python 3.12，并勾选“Add Python to PATH”。
2. 完整解压 `Viewledge-v1.4.5-windows.zip`，不要直接在压缩包里运行。
3. 双击根目录的 `start_web.bat`。
4. 首次启动会创建本机运行环境并安装基础依赖，请保持网络连接。
5. 等待浏览器打开本地工作台。
6. 在“API 配置”中填写你准备使用的服务信息。
7. 点击“新总结”，粘贴公开视频链接并开始处理。

## 能力如何选择

- 视频有平台字幕时，Viewledge 直接使用字幕，不需要云端转写或本地模型。
- 视频没有字幕时，默认可选择云端快速转写。
- 本地 CPU 转写需要另行安装 `Viewledge-local-asr-small-model.zip`。
- 本地 GPU 是高级可选能力，不影响平台字幕、云端转写和本地 CPU。
- 默认安装不会下载约 1 GB 的 NVIDIA 运行库，也不会自动下载语音模型。
- TED 等来源可能只能跳转原网站播放，但字幕、摘要和知识包功能不受影响。
- 缺少某项能力只会禁用对应选项，不会导致整个 Web 工作台崩溃。

## 数据与隐私

知识记录默认保存在当前 Windows 用户的数据目录，不写入程序源码目录。云端转写只在没有平台字幕且你选择云端路线时上传提取后的音频。API Key 仅由本地后端读取，不会写入知识包。

## 常见问题

- 提示 Python 版本不正确：安装 Python 3.12 后重新启动。
- 提示端口被占用：关闭旧的 Viewledge 命令窗口后重试。
- 提示数据目录不可写：选择当前用户可写的目录，不需要管理员权限。
- 某个处理选项不可选：打开能力检查或 API 配置，补齐该选项需要的能力。
